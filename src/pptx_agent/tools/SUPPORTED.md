# What the deck tools support

The tools in `pptx_agent.tools`, as a model sees them. Lengths are points, colours theme names
(`accent1`, `tx1 lumMod=75%`; PowerPoint's own names, `Text 1` or `background2`, are read
as them) or `#RRGGBB`. Every changing call is one undo step and returns
facts about the slides it touched (see [GUIDANCE.md](GUIDANCE.md)).

## Supported

| Feature | Tool / action | Notes |
|---|---|---|
| Open a deck or template; a new deck, from nothing or from a template | `open_document`, `new_document` | inputs are blobs the application registered; a template's slides are dropped from a new deck |
| Save as a deck, a template or a text outline | `save_document` (`pptx`, `potx`, `outline`) | refuses new validation problems; lists overflows, collisions and empty placeholders still there |
| Close a document | `close_document` | the session holds a few documents at a time |
| The deck at a glance | `describe` | slides with ids, titles, layouts and content areas; theme colours, fonts, roles and tints; the deck's table styles (its default, its own, how the built-in names go); masters and layouts with their ids (`M0`, `L2`), placeholders (and their ids and custom prompts) and the text on them that is not a placeholder (a legal line); comment counts |
| Read slides | `ppt_read_slides` (`outline`, `geometry`, `compact`, `svg`) | outline Markdown with ids; every shape's box, fill, outline and text; a row per shape (id, kind, box in whole points, fill, text size, first words; a group's members under it); an SVG view. Layouts and masters too (`L2`, `M0`, slides beside them), in `compact` and `geometry`: their shapes under their addresses (`L2.6`), each placeholder's type and idx, sizes inherited from the master; outline and svg are of slides (`describe` lists a layout's placeholders, `render` draws it) |
| Read a text input (CSV, Markdown, plain text) | `read_blob` | a page at a time |
| Find and replace text | `find_text`, `replace_text` | slides, notes, tables and SmartArt; `expect: one` or `all`; `stories: layouts`, `masters` or `all` reach the text on layouts and masters (a footer year, a legal line, a prompt), addresses `L2.5`, `M0.7` |
| Look at slides | `render` | PNG, at most 4 a call; with `sheet` (`{"columns": 4, "width": 480}`, `{}` for 4 of 360 px) up to 30 slides, layouts or masters as one image, tiled in order, each labelled with its number and id (`3 · s:258`, `· hidden` after a hidden slide's; `L2 Title Only`), `sheet.width` each tile's; says which text the image leaves out for want of a font (`missing_glyphs`) |
| Fit, collisions, validation, design facts | `check` | overflows, collisions (`boxes` too), shapes off the slide, empty placeholders ("Click to add text"), problem facts, design facts, validation |
| The tightest spacings on a slide | `check` with `spacing` (pt) | gaps between neighbours, padding inside cards and panels, clearance to the footer, slide number and date and past the layout's content area, as drawn, nearest first: measurements, no verdicts |
| Undo and redo | `undo` | one call is one step; refs come back with the state; undo by slide (`scope`) refuses a change to a layout or master the slide shows (`entangled`: other slides show it too) |
| Several calls as one step | `batch` | in order, checks once at the end; a failing op is skipped with its error and the rest apply (`atomic: true`: all or nothing) |
| Slides from a layout, with title, body and notes | `ppt_add_slide` | the deck's own layouts and placeholders |
| Slides from a Markdown outline | `ppt_draft_slides` | into the deck's layouts |
| Duplicate, move, delete a slide; find one by title; delete a slide's empty placeholders | `ppt_manage_slides` | a duplicate does not take its original's comments; `delete_empty_placeholders` keeps an empty title |
| Change a slide's layout | `ppt_manage_slides` `set_layout` (`slide`, `layout`: `L2` or its name) | as PowerPoint's Layout menu (measured): empty placeholders go and the layout's come empty; filled ones take the layout's placeholder of their kind (title; content, body or subtitle; a picture a picture or content placeholder), the same type first, both sides in idx order -- never by name -- and lose their own box for the layout's (text and formatting stay; the result lists `boxes_dropped`); a picture into a picture placeholder cropped to fill it, into a content one at its own size, fitted and centred; a table into a table or content placeholder at its width (columns scaled), a chart into any content, table or picture placeholder; dates, footers and slide numbers by kind, never added; content with no place stays where it was drawn, snapped to the nearer side, as an orphan (`orphans`, with why); other shapes untouched; one slide per call (`batch` for several), one undo step |
| Text of shapes, table cells and speaker notes | `ppt_set_text` | plain text keeps formatting; the text spec states runs, bullets, levels and the frame |
| Run, paragraph and frame formatting | `ppt_format_text` | bold, italic, underline, size, font, colour; alignment, levels, bullets, spacing; insets, anchor, wrap, autofit; table cells too, a whole table (every cell) or one row or column (`256.7/row0`, `256.7/col1`) |
| Autoshapes and text boxes | `ppt_add_shape` | every preset; `measure: true` sizes text first and adds nothing; `fit_height` |
| Position, size, rotation, flips, fill, gradient, outline, geometry | `ppt_set_shape` | only the fields given change |
| Connectors that stay attached | `ppt_add_connector` (`straight`, `elbow`, `curved`) | glued to a shape's side, or between points; arrowheads |
| Z-order, group, ungroup, duplicate, delete | `ppt_arrange` | |
| Grid and flow | `ppt_arrange` (`grid`, `flow`) | the targets in the order given, row by row, in `columns` (and `rows`) equal cells of a `box` or the content area, `gap` apart (`gap_y` between rows): shapes sized to their cell, pictures keeping their aspect, centred; `flow` keeps their size and wraps; refused when the cells do not fit; one undo step, each target's box returned |
| Align and distribute | `ppt_arrange` (`align`, `distribute`) | align an edge or centre to the targets' bounds, the slide or the content area; distribute with equal gaps between the outermost targets or across the content area, or with a fixed gap; one undo step, the boxes returned |
| Pictures: insert, replace, fill a picture placeholder | `ppt_add_picture` | from an image blob; replacing keeps the frame, height or width; an empty picture placeholder (`target`) takes the picture cropped to fill its box, keeping its id and name |
| SVG pictures | `ppt_add_picture` with an `image/svg+xml` blob | stored as PowerPoint 2016 and later store an inserted SVG: the vector, which PowerPoint can recolour, and a PNG fallback made for it; insert and replace |
| Recolouring an SVG picture | `ppt_set_shape` `fill` and `line` (`color`, `width`) on the picture | as PowerPoint's Graphics Fill and Outline (measured): every shape of the SVG filled with the colour (outline shapes too) or stroked with the line colour and weight, the PNG fallback drawn again; a theme colour resolved against the slide's theme and kept linked through PowerPoint's class for every slot; a transparency (`accent2 alpha=50%`) as the fill's opacity; the SVG's styles carried over; on a bitmap picture `fill` and `line` are its background and border, as in PowerPoint |
| Brand assets (icons, logos) | `ppt_find_asset`, `ppt_add_picture` `asset` -- only when the application configured a catalogue (`deck_format(assets=...)`) | search by words: ids, names, keywords; insert or replace by id |
| Tables: new; cells, rows, columns, merges, widths, heights, fill, borders; style and Table Design flags | `ppt_add_table`, `ppt_edit_table` (`set_style`, `set_flags`) | cells by row and column or by their labels; a style by name or id, the deck's own (a template's) or any of PowerPoint's 74 built-in styles; header row, total row, first and last column, banded rows and columns |
| Tables from data: a dataset (`d:<id>`) or another open document's table (`t:<name>`) | `ppt_add_table`, `ppt_edit_table` (`set_cells`) with `from`, `from_columns`, `header`, `date_format` | every source row, the columns picked by name; a header row of the column names unless `header` gives its texts (`[]`: none); numbers as a chart's category labels write them, in the session's locale; dates in the locale's day order, or in a pattern with `date_format` (`d mmmm yyyy`, `dd/mm/yyyy`; names measured per locale); a source too big for the table is refused, never cut; the result's `data.from` gives each placed column's table column, source rows and their sources (the deck keeps it too, as a tag on the frame: `session.provenance(doc)`, `Document.provenance()`; edits without a source drop the columns or rows they make untrue) |
| Figures in text from a dataset or another open document's table | `ppt_set_text`, `ppt_add_shape`, `ppt_add_table` (`data`), `ppt_edit_table` (`set_cells`), `replace_text` (`replace`): `{{d:<id>/<key>/<column>}}`, `{{t:<table>/<key>/<column>}}`, `#3` for a row by position, `:0`/`:0.0`/`:#,##0`/`:0.0%` to format, `:d mmmm yyyy`/`:dd/mm/yyyy` for a date | the value in the session's locale (a table cell's text, a percent column as a percent); the result's `data.facts`; the deck keeps each as a fact on its shape (`Document.provenance()`, `facts`) while its text is where it says; `\{{` writes a reference literally; speaker notes and SmartArt keep no facts |
| A slide's number in text, kept current | the same tools: `{{slide:s:<id>}}` or `{{slide:$ref}}` | the number the slide's slide-number field shows (position + `firstSlideNum` - 1, hidden slides counted), rewritten after every add, delete, move or duplicate of slides and on save (`checks.slide_numbers`, `save_document`'s `slide_numbers`); a deleted slide's keeps its last number and is listed (`missing_slides`); not kept in speaker notes, SmartArt or shapes copied to another deck; stale after PowerPoint reorders the deck, until it is saved here |
| Charts: new from data; read; values, categories, series, titles, axis titles, legend, data labels, gap width, axis scales, gridlines, series and point colours and markers, a column series as a line, chart text, point labels | `edit_chart` | column, stacked column, bar, stacked bar, line, pie, scatter, radar (lines), filled radar, bubble, as PowerPoint inserts each; point labels from the workbook as PowerPoint's Value From Cells; `add` takes the frame, scale, gridlines, legend, number format, data labels, series colours and text style in one call; a scale without `axis` is the value axis where the chart has one (a scatter's x or y, a date or secondary axis must be named); the embedded workbook changes with the chart |
| SmartArt: node text, adding and removing nodes | `edit_smartart` | diagrams already in the deck; PowerPoint lays the diagram out again on opening |
| The theme's colours and fonts | `ppt_set_theme` | every theme reference in the deck follows |
| A long table continued on the next slides, the header repeated; fewer rows of a source | `ppt_add_table` with `continue: true`; `from` a row range (`t:items/#1:#9`, `d:by_region/#10:`) | new slides right after the target, on its layout, with its title text and its other empty placeholders deleted, the table in the same box; every row at its measured height; the result lists each page (slide, table, source rows, height, `from`), each table keeps its own record; `rows` fewer than the source is refused, offering the row range |
| Measuring a table before placing it: each row's drawn height and the pages its rows split into, the header repeated | `ppt_add_table` with `measure: true` (`size`, `widths` as an add takes them) | the same arguments as an add, `from` and literal cells alike; a page is the box's `h` or the slide's content area; pages number the rows below the header from 1 (with `from`, its source rows); nothing is added, the version stays |
| Slide master and layout shapes: text, formatting, fill, position, size, delete, pictures; new text boxes, shapes, pictures (SVG too), connectors and tables on them | `ppt_set_text`, `ppt_format_text`, `ppt_set_shape`, `ppt_arrange`, `ppt_add_shape`, `ppt_add_picture`, `ppt_add_connector`, `ppt_add_table` with addresses `L2.5`, `M0.7` (`slide: L2` or `M0` to add) | the same edits a slide's shapes take; every result lists the slides it `affects` and checks them; a slide's own placeholder text and overrides stay; deleting a layout or master placeholder that slides or layouts inherit from is refused, with the list |
| A layout placeholder's prompt text ("Typ hier uw bevinding") | `ppt_edit_master` `set_prompt` | the first level (`\n`: the next ones), formatting and levels kept, `hasCustomPrompt` set, as typing it in Slide Master view does; shown in an empty placeholder while editing, never in a show or export |
| Header & Footer: footer text, slide number, date (updating or fixed), not on title slides | `ppt_edit_master` `set_footer` | Apply to All (masters, every layout and every slide, as PowerPoint writes it) or Apply (`slides`); turning one off removes it from the slides |
| A layout's own placeholder: a text, content or picture box (or a title on a layout without one) each slide on it fills | `ppt_edit_master` `add_placeholder` (`type`, `box`, `text` the name; `slides` to add it, empty, to slides already on it; target `L2.7` later for more slides); `ppt_set_text`, `ppt_add_picture` `target` fill it on a slide | a unique `idx` (largest on the layout plus one, at least 13, inferred from Office's bundled layouts); slides made afterwards get it empty and inherit its place, as in PowerPoint; slides already on the layout do not unless given in `slides` (PowerPoint: when the layout is applied again). Move, resize, rename, prompt, format or delete it as any layout shape (`L2.7`). Table and chart placeholders: not added |
| Layouts: add (a custom layout), duplicate, rename, delete | `ppt_edit_master` `add_layout`, `duplicate_layout`, `rename_layout`, `delete_layout` | as Slide Master view does; a layout in use is not deleted unless its slides move to another (`reassign_to`); names stay unique on a master; ids (`L2`) are the file's own and PowerPoint keeps them |
| Document properties | `set_properties` | title, author, language, subject |
| Comments: threads on a slide or a shape, replies, resolving | `ppt_comments` (`list`, `add`, `reply`, `resolve`, `reopen`, `edit`, `delete`) | PowerPoint's modern (threaded) comments |
| Design facts of a slide | `ppt_design_facts` | palette, sets of like shapes and legends, empty regions, alignment, vocabulary, text sizes, lines over text: facts, no verdicts |
| Compare a run of like slides | `ppt_compare_slides` (`slides`, at least two) | corresponding shapes matched (placeholders by type and idx, then unique names, then kind and nearest box -- a shape renamed on some slides too, its name then a difference: the majority's and the others'); per shape, where box, text size (per level), text colour, typeface, fill or outline differ from the majority, near-misses (2 pt; a colour 8 of 255 per channel) apart from larger differences, `from` (slide, layout, master) where sources differ, a one-call `fix` for the near-misses; shapes missing on some slides or found on few: measurement only |
| Layout facts after an edit | `checks.layout` on changing calls | near-alignment, uneven gaps, outlier text sizes, labels far from their markers, each with its exact fix |

## Not supported

- **Animations and transitions.**
- **SmartArt creation:** build the graphic with shapes and connectors (`ppt_add_shape`,
  `ppt_add_connector`); existing SmartArt can be edited.
- **Icons** (PowerPoint's icon library): no icon library is provided. An icon the
  application brings as SVG can be inserted (SVG pictures, above), or searched and
  inserted from the application's own catalogue (brand assets, above).
- **Video and audio.**
- **Sections** (grouping slides into named sections).
- **Hyperlinks:** no links between slides, and no listing or editing of links. (A web address
  can be put on a run of text through the text spec's `hyperlink`; nothing more.)
- **Action buttons** and other click or hover actions.
- **Masters themselves:** a master's shapes, its layouts and Header & Footer can be edited
  (above); adding or deleting a slide master, the master's text styles (the levels' sizes and
  bullets) and backgrounds are not. Text fit is measured on the slides a layout or master
  edit affects, not on the layout itself.
- The older, non-threaded comments (`ppt/comments/comment<n>.xml`) are not read or written.
